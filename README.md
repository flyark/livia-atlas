# LIVIA Atlas

A searchable atlas of AlphaFold-Multimer protein–protein interaction predictions resolved to residues: for a protein, the partners predicted to bind it, how confident each prediction is, and where on the protein each partner binds, for human, mouse, rat, fly, zebrafish, *C. elegans*, yeast, viruses and other species, with orthologs side by side.

**Web:** https://flyark.github.io/livia-atlas/ · **Data:** [Zenodo, doi:10.5281/zenodo.22964479](https://doi.org/10.5281/zenodo.22964479) · **Built with:** [LIVIA](https://flyark.github.io/LIVIA/)

**Cite:** Kim A-R, Perrimon N (2026). LIVIA: a browser-based tool for assessing and visualizing predicted protein interactions. *bioRxiv*. [doi:10.64898/2026.05.01.721633](https://doi.org/10.64898/2026.05.01.721633)
