# LIVIA Atlas (beta, under development)

A searchable atlas of AlphaFold-Multimer protein–protein interaction predictions, scored with [LIVIA](https://flyark.github.io/LIVIA/) and resolved to residues. It draws on many published interactome datasets across species: for a protein, the partners predicted to bind it, how confident each prediction is, where each partner binds, and its orthologs side by side. Details, including the datasets and their sources, are on the site.

**Site:** https://flyark.github.io/livia-atlas/

**Cite:** Kim A-R, Perrimon N (2026). LIVIA: a browser-based tool for assessing and visualizing predicted protein interactions. *bioRxiv*. [doi:10.64898/2026.05.01.721633](https://doi.org/10.64898/2026.05.01.721633)
